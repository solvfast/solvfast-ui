## 6. Result schema (results.json, one entry per test; rows aggregated)

```
{ requirement_ids[], test, feature, expected, cite[], environment { site, url, frappe }, users[],
  result: PASS | FAIL | BLOCKED, actual { checks[{ label, ok, expected, actual }], records[] },
  evidence [{ as, user, http, path, args (shape), status, exc_type, content_type, response_shape } | { screenshot }],
  issue (fix / follow-up), source: "real-server" }
rows: { requirement_id, requirement, p35_status, category, sub, tests[], result, source }   — source "simulator / unit (P35
evidence; not re-run here)" for (a) / (b) rows without a real-site test
```
Secrets never enter the files: every request / response passes `redact()` (guards.mjs) and only shapes are kept.

## 7. Expected Frappe behaviours the owner should know before the run

These come from reading the 15.110 source; each is asserted (or recorded) by the named test, so the run will confirm or refute it.

- The server enforces only `reqd`; `mandatory_depends_on` is a client rule — the package must block it (and does on the simulator). (F-REQ-2, F-REQ-3)
- A permlevel-1 write by a user without that level returns 200 and silently keeps the stored value (not a 403). (F-PERMLEVEL-2)
- Lists drop non-permitted permlevel fields silently; User Permissions filter list rows silently but `getdoc` of a hidden record is 403. (L-PERM-2, L-PERM-1)
- Amending is an insert: the server checks `create` and that the source is cancelled, not the `amend` right — 'Amend needs amend + create' is a client gate. (F-AMEND-2)
- List Filter grants read / write / create / delete to every Desk User with no owner rule: anyone may create global filters or delete another user's filter. (L-SAVED-2)
- `toggle_like` has no permission check. (L-LIKE-1)
- Sidebar `assigned_to` counts are built with `frappe.qb.get_query` (listview.py:36-58); whether User Permissions apply there is recorded. (L-GROUP-1)
- `export_query` writes an Access Log before refusing a user without `export`. (L-EXPORT-1)
- `user_settings.save` merges shallowly: a Desk save of `List` without `sf_ui` drops it (LV.A6b). (L-USERSET-1)
- Bulk submit / cancel / update return HTTP 200 with a per-document failed list; bulk delete reports failures by realtime msgprint. (L-BULK-2, L-BULK-3)
- Since 0.7.0-dev.2 the package's `selectionMode` default is `"header"` (Desk's header actions, P36 owner decision); the run confirms Desk's swap and per-action selection outcome on a real site. (L-HDR-1)
